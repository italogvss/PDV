# Ajustar estoque

Use o ajuste de estoque para corrigir a quantidade de um produto sem precisar editar o cadastro inteiro — útil em casos de perda, quebra, contagem de inventário ou reposição manual.

## Passo a passo

1. Acesse **Estoque** no menu lateral.
2. Na lista de produtos, clique no menu **⋮** da linha do produto e selecione **Ajustar estoque**.
3. Use os botões **+** e **–** (ou digite o valor diretamente) para definir o ajuste — valores positivos somam ao estoque atual, valores negativos subtraem.
4. Confira o **Novo estoque** calculado antes de confirmar.
5. Clique em **Confirmar ajuste**.

## Observações

- O ajuste é sempre relativo ao estoque atual — não é possível deixar o novo estoque negativo.
- O estoque máximo permitido por produto é 9999 unidades.
- Toda venda finalizada já reduz o estoque automaticamente; use este ajuste apenas para correções manuais, fora do fluxo normal de venda.
- Cancelar uma venda também devolve os itens ao estoque automaticamente — veja o artigo *Cancelar uma venda*.
