# Exportar seus dados

Você pode baixar os registros do seu negócio a qualquer momento, em arquivos **`.csv`** (abrem no Excel, Google Planilhas e afins).

## Onde fica

Acesse **Configurações > Backup & dados**. No cartão **Exportar dados**, clique no botão da categoria desejada — o download começa na hora.

## O que dá para exportar

- **Vendas** — histórico completo de vendas.
- **Produtos** — catálogo do estoque (nome, código de barras, NCM, estoque, preço).
- **Clientes** — cadastro de clientes com contato e endereço.
- **Serviços** — serviços cadastrados.
- **Despesas** — lançamentos de despesas.
- **Faturamento** — resumo financeiro.
- **Equipe** — funcionários.

## Observações

> A exportação continua **disponível mesmo se a assinatura estiver cancelada ou vencida** — é justamente o que permite baixar seus dados antes do fim do período de retenção.

> Se a loja estiver com **exclusão agendada**, exporte tudo o que precisar antes da data indicada no aviso. Depois dela, os dados não podem ser recuperados.

O arquivo exportado serve de **modelo** para a importação: veja o artigo *Importar dados via CSV*.
